# ☁️ Weather App

A weather application that fetches real-time weather data using OpenWeather API. Users can search for any city and get current weather details.

---

## 🚀 Features

- Search weather by city name
- Shows temperature and weather condition
- Real-time API data
- User-friendly interface
- Error handling for invalid cities

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Fetch API)
- OpenWeather API
